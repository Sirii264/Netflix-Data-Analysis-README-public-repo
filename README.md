# Netflix Data Analysis

## Project Overview
This project analyzes Netflix Movies and TV Shows dataset using Python and Data Visualization libraries.

The analysis focuses on:
- Content distribution
- Release trends
- Genre popularity
- Country-wise production
- Ratings analysis
- Movie duration analysis

---

## Tools & Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Visualizations Included
- Movies vs TV Shows
- Netflix Release Trends
- Top Countries Producing Content
- Top Genres on Netflix
- Ratings Analysis
- Movie Duration Distribution

---

## Key Insights
1. Movies dominate Netflix content.
2. USA contributes the highest amount of content.
3. Netflix content rapidly increased after 2015.
4. Drama and International genres are highly popular.
5. Most Netflix content is targeted toward mature audiences.
